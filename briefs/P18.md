## Goal
Konrad (2026-10-13): "we will go with swarmhub name for now." The app's visible name becomes **SwarmHub**. The risk is on record and is

Keep unchanged, so nothing is lost: the internal codename `AgentApp` (binary, module, target, data folder

## Must do
1. **One source of truth.** `AppConstants.name = "SwarmHub"`. Every user-visible string that names the app reads `AppConstants.name`
   (window/menu names, the composer placeholder, Settings copy, model-role labels such as "Torvli default", Usage, alerts). No literal app name
   remains in `Sources/` outside `AppConstants` and comments. `Info.plist` `CFBundleName` and `CFBundleDisplayName` = SwarmHub (a test asserts
   they equal the constant).
2. **Packaging and install.** `scripts/package-release.sh` builds `SwarmHub.app` and `dist/SwarmHub-<sha>-arm64.zip` with the same signing
   identity. Install to `~/Applications/SwarmHub.app`; if `~/Applications/Torvli.app` exists, quit it by exact pid and move it into
   `~/Applications/Torvli-backups/` (P6 backup rule), so only one copy remains and Spotlight finds SwarmHub.
3. **Network identity.** The honest user-agent becomes `SwarmHub/<version>` for Grok (`GrokRequestHeaders` / `GrokProtocol.userAgent`; add a
   dated drift-register entry "renamed from Torvli/<version>, Konrad's rename"; P10c's live step re-confirms Grok accepts it) and for Hermes
   (`AppVersion.swift`).
4. **Updates.** The releases URL becomes `github.com/conrader/swarmhub`. GitHub redirects `conrader/torvli` both before and after the repo rename,
   so Updates keeps working either way (test with the URLProtocol mock).
5. **Paths that carry the old name, without moving Konrad's data.** The Grok export default becomes `~/Documents/SwarmHub Grok Export`; the
   exporter, the importer and P9's box importer docs read the old `~/Documents/Torvli Grok Export` when the new one does not exist. The self-test
   session prefix becomes `swarmhub-selftest-`, and everything that recognises self-test sessions accepts both prefixes. The snapshot cache becomes
   `~/Library/Caches/SwarmHub-snapshots` (the old folder is left alone). `.gitignore` covers both export folder names.
6. **Words.** README (title, feature table, install steps), `PLAN.md` title, `THIRD-PARTY-NOTICES.md` header, script help text. Briefs and docs
   keep their history and are not edited.
7. **Tests.** A guard test fails if any Swift file under `Sources/` contains the literal old name outside comments and `AppConstants`; tests that
   asserted "Torvli" strings now assert `AppConstants.name`; default parallel `swift test` green; Python tests green.
8. **Live, read-only.** Package + reinstall, then `--check-bots` (16 OK, key present for all 16, which proves the Keychain carried over),
   `--render-snapshot` into the new cache folder, and `open ~/Applications/SwarmHub.app --args --ui-smoke …/ui-smoke.json` (errors empty; the
   report states the app name and window title). Leave SwarmHub running.
