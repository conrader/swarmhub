## Goal
Bot avatars become BotAvatarsKit marks (Jakub Antalik, Libraries.dev, MIT) that look as on Grok: one of its shapes in one of its 11 colours (derived
from the id when a bot has no avatar words), a cluster of member marks for a group. **Motion by context:** a list row (sidebar, members) stays still unless that bot is working or
hovered; the open bot's large mark (chat header, Overview) and showcase views (welcome, empty states, import finished) run a gentle idle (blinks,
glances, slow turns, no flips); in a group header the answering member works and the others follow the list rule; a working bot hops wherever it
appears. Settings → Appearance → Avatar motion: By context (default), Calm everywhere (list rule for every view), Off. macOS Reduce Motion always
wins (still). Palette: black #000000 (white in dark mode), brown #936439, red #FF263C, orange #FF6700, yellow #FF9800,
green #00C972, cyan #00BCA6, blue #1084FE, violet #9159FE, magenta #FF309B, gray #777777. Looks to match (from Grok Bot 0.70.2's code, never seen on
screen). Stored in Grok: Jarvis blob/black, Infra cylinder/violet, Finance Controller gem/yellow, Reactor hex/orange, DMT leaf/green, Admin
shield/blue, Achilles shield/yellow. Derived from the id: Boppy blob/blue, Botsilo cloud/blue, Ermes tablet/green, Vised wedge/red, Doc
teardrop/brown, Plainsay hex/blue, NetROAS tablet/gray, Saldora tablet/brown, Rapper blob/green. Group "Konrad, DMT, Achilles": DMT leaf/green +
Achilles shield/yellow.

### Part B — the model, Grok's default look, the store (needs no kit)
5. **Model** (`Avatars/AvatarMark.swift`): `AvatarMark { shape: String, colour: String }` holds Grok's words verbatim, never kit enums (open sets; the
   25 valid shapes are in `docs/avatars-research.md`); `AvatarColour` = the 11 hexes, black → white in dark. `Bot.avatarMark: AvatarMark?` is
   additive: nil default, one CodingKeys case, `try?`-decoded (a bad mark must not cost the store), StoreFile stays version 2. **`avatarName` and
   `accentColor` still decode and encode unchanged; no case or order of the 21 changes** (an unknown `avatarName` fails the whole store; a rollback
   must still open it). Pure `AvatarLook.resolve(mark:classic:seed:)`: no mark → today's classic avatar; else the bare silhouette, each field the
   stored word if exactly valid (case-sensitive, as Grok) else derived. Seed = `grokSourceID ?? id.uuidString.lowercased()`, never re-cased or
   UUID-parsed.
6. **Default look** (`Avatars/GrokDefaultLook.swift`, our code; constants frozen once shipped). H = 32-bit FNV-1a over the id's UTF-16 units (offset
   0x811C9DC5, prime 0x01000193). Shape: x=H; x=(x^(x>>16))*0x045D9F3B; x=(x^(x>>13))*0xC2B2AE35; x^=x>>16; `x%8` → blob, pebble, squircle, tablet,
   wedge, hex, cloud, teardrop. Colour = mulberry32(H) first output: t=H+0x6D2B79F5; n=(t^(t>>15))*(t|1); n=(n+((n^(n>>7))*(n|61)))^n; r=n^(n>>14);
   `(UInt64(r)*10)>>32` → brown, red, orange, yellow, green, cyan, blue, violet, magenta, gray (wrapping `UInt32`, logical shifts). Vectors (id →
   FNV/shape/colour → look): `""` 811C9DC5/5/6 hex/blue; `aaaaaaaa-bbbb-4ccc-8ddd-eeeeeeeeeeee` 615299A2/1/2 pebble/orange, upper-cased 0CEB1322/2/0
   squircle/brown; "zolw-" + U+1F642 2584CD0D/7/9 teardrop/gray. The nine real bots: a **local-only** test (skipped without
   `~/Documents/Torvli Grok Export`) compares each bundle's derived look with the table above by name; no real id enters the public repo or the report
   beyond 8 characters. **The exporter does not change** (`export-grokbot.py`, Swift twin, golden fixtures): null is the tested record of Grok's empty
   field, P10 retires the script, the rule is pure.
