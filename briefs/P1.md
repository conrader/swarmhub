## Must do
1. **Multiplex-off guard.** If the gateway has `multiplex_profiles` off, it ignores `/p/<profile>/`
   and silently answers as the default agent with HTTP 200. With multiplex on, `GET /p/<p>/v1/models`
   returns `data[0].id == "<p>"`. Make profile discovery and the Settings "Test" treat a named profile
   whose `/v1/models` id ≠ the profile name as NOT available, with a clear message
   ("Server ignored the profile prefix — enable gateway.multiplex_profiles"). Never create or route
   a bot to such a profile.
2. **Names from slugs.** A discovered profile `grok-jarvis` becomes a bot named "Jarvis";
   `finance-controller` → "Finance Controller"; strip a leading `grok-`. Keep `hermesProfile` exact.
   Discovery stays idempotent (no duplicate bot per profile; never removes user bots).
3. **One paste flow.** In Settings → Hermes, a single "Add bots from box" multi-line field that
   accepts `profile=key` lines (also comma-separated, which exists today). On save: store each key in
   Keychain `hermes.<profile>`, add the profile to the named-profiles list, run discovery, report
   per-profile result (added / already present / rejected + reason). Keys never appear in logs,
   store.json, UserDefaults or error text.
4. **Template import binding.** When an imported template/bundle has a slug `S` and a Keychain key
   exists for `grok-S` (or for `S`), bind the imported bot to that profile and say so in the
   import report row "Hermes profile" (currently always "default", TemplateImport.swift ~228).
   Otherwise keep the default-profile behaviour.
5. **Split `Tests/AgentAppTests/AgentAppTests.swift` (734 lines)** into functional files each ≤500
   lines (e.g. TestSupport.swift for TestBackend/helpers, ApprovalsTests, HermesBackendTests,
   TemplateImportTests, StoreTests). No test may be dropped; count before and after must match
   plus your new tests.
6. Tests (synthetic, URLProtocol-mocked or TestBackend) for 1–4: multiplex-off rejection,
   slug naming, idempotent discovery, paste parsing incl. whitespace/blank lines/`=` inside keys,
   import binding with and without a matching key.
