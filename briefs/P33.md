# P33 — Spread the crowded Overview over tabs

Konrad, 2026-10-14: "overview tab is too crowded - it needs to be spread out to other tabs". **Accepted by that
message; the split below is the default.**

Today (`Views/InfoPanel.swift`, `BotCapabilitiesView.swift`, `ModelSectionView.swift`) Overview stacks: identity,
description, Memory (or the OpenClaw section), the whole Model section (picker, roles readout, sub-agents lines,
mismatch/switch), SwarmHub skills + box Skills + Tools + Imported, the Approval policy with up to 20 audit entries, and
Delegated tasks. Tabs: Overview · Routines · Media · Computer · Members.

## New tabs (order) and what moves
- **Overview** — identity (avatar, name, title, Hermes version), description, one model line (current model + "last
  reply" when set, the change menu; details live in Model), memory line (P32 copy) or the OpenClaw status section,
  a one-line status per other tab when it needs attention (e.g. "SwarmHub skills: update available ›",
  "1 approval waiting ›", "Model differs from this bot's role ›") that switches to that tab. Members' content (owner,
  agent, groups, "New group with …") moves to the bottom of Overview; the Members tab goes.
- **Model** — the full Model section: picker, Conversation/Coding/Sub-agents roles, mismatch + "Switch this chat",
  box default; P31's Coding agent and sub-agent model rows land here later.
- **Skills** — SwarmHub skills (install/update banner), box skills, tools, imported skills.
- **Activity** — approval policy + audit, delegated tasks (P32 item 2); P31's coding jobs land here later.
- Routines, Media, Computer unchanged.

## Rules
- The tab bar must fit the panel's minimum width (300 pt) with no truncation or wrapping at the default text size;
  if seven text labels do not fit, use a compact style (SF Symbol over a short caption, or symbol-only with
  `.help` + accessibility labels) — render both widths (300 and 380) and pick what reads clearly; say which.
- Keep `store.infoTab` and existing keyboard shortcuts working (AppCommands enums updated; new tabs get the next
  shortcuts); anything that today opens Overview to show a section (banners, "Change model…", skill install) opens the
  tab that now holds it.
- No behaviour change inside the moved sections; OpenClaw agents show only the tabs that have content for them.
- Renders of every tab for a Hermes bot and an OpenClaw bot, at both widths; the headless inspector render updated.
