Read `PLAN.md` first; its standing constraints apply. Start from `main` (P1 merged).

Grok, including its history.

## Data sources on THIS MacBook (Konrad's own data — read-only, never commit, never print message text)
- Grok Bot app cache: `~/Library/Application Support/Grok Bot/sand-client-persistence/*.blob`. File names are
  lowercase base32 (no padding) of keys like
  `sand.client.slice.account.<account>.transcript.replicas.<botUUID>` (one per bot/group: 17) and
  `…roster.last-roster` (bots: names, titles, descriptions, avatar shape/colour, group members). Each blob is JSON
  `{"schemaVersion":1,"value":{"entries":[…]}}`. Entry kinds: `message` (fields like role, content, richText,
  timestampMs, seq, fromAgent/toAgent), `send-message` (user messages: field `message`), `event`, `notice`.
  Inspect the real structure yourself, but only report shapes/counts.
- The cache holds the latest 62–200 entries per conversation; older history exists only on Grok's servers.
- Server-side profiles already exist for 16 bots: `grok-<slug>` on Konrad's Hermes box, base
  `https://konrad.agenthut.net/p/grok-<slug>/v1`, default profile at `https://konrad.agenthut.net/v1`.
  Slugs: achilles admin boppy botsilo dmt doc ermes finance-controller infra jarvis netroas plainsay rapper
  reactor saldora vised. Bot UUID ↔ slug: match by roster name (lowercased, spaces→`-`).

## Must do
1. **Exporter** `scripts/export-grokbot.py` (python3 stdlib, runs with /usr/bin/python3 on macOS): reads the cache,
   writes an `agentapp-bot-bundle/v1` export (spec: `docs/agentapp-bot-bundle-v1.md`; extend it compatibly and
   document any additions, e.g. `profile` per bot and group members) to `~/Documents/Torvli Grok Export/`
   (dirs 0700, files 0600). Messages: user (`send-message` + role user) and assistant text in order with timestamps;
   tool/reasoning/injected-context entries dropped; hidden-prompt markers such as `[GROK_BOT_HIDDEN_PROMPT]`
   entries kept but flagged `hidden: true`. Run every text field through a secret filter (reuse the patterns in
   `Sources/AgentApp/TemplateImport/TemplateImport.swift`, ported to Python) replacing hits with `[REDACTED]`.
   Print only counts per bot.
2. **Importer** in the app for that export (folder with `index.json`, or one `bundle.json`), via the existing
   Template Import UI AND a headless CLI: `AgentApp --import-grok "<folder>"` that writes the same result into the
   real store.json and exits (no window). Reject unknown `format`. Mapping: name, title, description→persona via the
   secret filter; Grok avatar shape+colour → our own avatar + accent (table in code; never Grok assets); profile
   `grok-<slug>` binding (Hermes backend, base URL `https://konrad.agenthut.net/v1`; key looked up in Keychain
   `hermes.grok-<slug>` at send time — missing key = bot shows "Add key" state, not an error spam); rename events as
   system lines; the group conversation becomes a group chat if P5 exists, otherwise an archived read-only
   conversation listing its members.
3. **History**: imported messages are a read-only "Grok history" archive per bot shown above the live chat
   (collapsed by default with a count, expandable, searchable, labelled "Imported from Grok Bot"), stored in a per-bot
   file next to store.json (lazy-loaded), never sent to Hermes as turns. Re-import (same `source_id`) updates
   without duplicating bots or messages (dedupe by entry id/seq).
4. **Keys CLI**: `AgentApp --import-keys <file>` reads `profile=key` lines from a file that must be mode 0600 and
   owned by the user, stores each in Keychain `hermes.<profile>` (`default=` → account `hermes`), then overwrites and
   deletes the file; prints only profile names and OK/failed. (Konrad decides separately how keys arrive; don't fetch
   any.)
5. Tests with SYNTHETIC fixtures only (`Tests/Fixtures/grok-cache/` with fake base32-named blobs; `Tests/Fixtures/
   bundles/`): exporter is Python — add `scripts/test_export_grokbot.py` (unittest) and run it; importer: mapping,
   lazy archive, idempotent re-import, unknown format, key-file permission check (reject 0644), avatar table.
6. **Run it for real on this Mac** after tests pass: run the exporter, then `--import-grok` into the real Torvli
   store (back up `~/Library/Application Support/<store dir>/store.json` first if it exists), then report per bot:
   name, profile, history message count, avatar mapping — no message text.
7. Package `./scripts/package-release.sh` and install: copy `dist/Torvli.app` to `~/Applications/Torvli.app`
   (replace an older copy; keep a backup of any previous `~/Applications/AgentApp.app`/`Torvli.app` in
