## Must do
1. **Rows** (`SidebarView.swift` `BotRow` and `GroupRow`): mark 36 pt (P15 `BotAvatar`/`GroupAvatarStack`, motion `.list` unchanged), a
   two-line stack: name 15 pt medium, fragment 14 pt `.secondary`, both `lineLimit(1)` with tail truncation; row height 58, horizontal padding 12,
   gap mark→text 12; selected = `AppColor.selection` rounded 10, hover = a fainter fill; unread = name semibold plus the existing dot at the trailing
   edge; muted group keeps its bell. No `MY BOTS` / `GROUPS` / `WORKSPACE` labels: one list, bots then groups in today's order; "Hidden chats"
   stays as a quiet disclosure at the end of the list.
2. **The fragment** (one pure function, tested): the newest visible message of that chat, whitespace collapsed, markdown stripped to plain text,
   prefixed "You: " when it is the user's; while the composer of that chat holds unsent text, "Draft: <text>" instead (as Grok); while the bot is
   working, "Typing…"; a chat with no live messages shows the newest line of its Grok archive; nothing at all → empty second line kept for even
   rows. Group rows: "<Member>: <text>". Never fetch from the server for this (local store only); cheap enough to recompute on every store change.
3. **Status badge**: a small (about 12 pt) circle on the mark's lower right for a bot needing attention (pending approval, or failed/incomplete
   last turn once P16 lands); none otherwise. Not drawn on group clusters.
4. **Top row** (after P14's slim row): sidebar toggle, then two 32 pt round buttons with a subtle filled circle: search (opens the existing command
   palette / chat search) and + (a menu: New bot, New group, Import template, and Import from Grok Bot once P10d lands). No title.
5. **Bottom bar**: a 32 pt round button with the user's initial (from Settings → Account name, default "K") opening Settings, and a pill button
   "Settings" (Grok's "Connect apps" has no equivalent; do not invent one). Height and padding as the reference.
6. **Width**: sidebar column ideal 280, min 240, max 320.
7. **Tests**: the fragment function (user/bot/group/draft/typing/archive/markdown/empty), row height constants, no section labels rendered;
   `--render-snapshot` PNG of the sidebar for Konrad's look; default parallel `swift test` green; files ≤500 lines (split `SidebarRows.swift` if needed).
8. Package + reinstall (signed; backup rule), `--check-bots`, `--ui-smoke` (errors empty), leave the app running.
