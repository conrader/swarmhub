# P53 — Every account named by its own name, tested live first

Konrad, 2026-10-16: "can we name calendar by account ? right now its a number" … "We should ALWAYS name it by name -
unless name is not there" … "can you fix this and test the fix before building ?". Not released until Konrad names a
release; the fix is checked against his real accounts with a read-only command before any release.

## Rule
Every connected account shows its own name (email, username, user @ workspace). "<App> account N · <date>" only when the
app gives no name. A name set with Rename… is never overwritten.

## Naming (`AccountProfileName.swift`)
1. Known identity tools (Composio v3.1 docs, 2026-10-16; field names are not documented, so they are found by search):
   gmail `GMAIL_GET_PROFILE`; github `GITHUB_GET_THE_AUTHENTICATED_USER`; googlecalendar
   `GOOGLECALENDAR_GET_CURRENT_USER` (no args; "email when available"), fallback `GOOGLECALENDAR_CALENDAR_LIST_GET`
   with `calendarId: "primary"`; googledrive `GOOGLEDRIVE_GET_ABOUT` with `fields: "user"`; slack `SLACK_TEST_AUTH`;
   notion `NOTION_GET_ABOUT_ME`. One line per app.
2. Any other app: find its identity tool among the app's tools by name (`*_WHO_AM_I`, `*_GET_CURRENT_USER`, `*_GET_ME`,
   `*_GET_ABOUT_ME`, `*_GET_PROFILE`, `*_GET_AUTHENTICATED_USER`, `*_GET_ABOUT`), only if P52 classifies it as a read
   with no required arguments.
3. Reading the name from the result: Composio often returns `data` as a JSON **string**; decode it when it is one. Then
   search the whole result (depth ≤ 6) for the first non-empty value under these keys, in this order: email,
   emailAddress, email_address, mail, userPrincipalName, login, username, user_name, handle, display_name,
   displayName, real_name, name. For Slack, if both a user and a team/workspace name exist, use "user @ team". Values
   are trimmed, ≤ 80 chars, one line.
4. Unnamed accounts are retried on every refresh (not once per launch), with a back-off of ≥ 10 min per account after a
   failure. Saving stays `PATCH alias` with the P48 409 suffix rule.

## Live check before release: `--check-account-names`
A headless command (like `--check-reports`) that reads the real store and connected-apps configuration **read-only**,
reads the Composio key the same silent way the app does, and for each connected account runs only the identity call
above. It prints one line per account: app · tool used · the key path where the name was found · the name, or "no name:
<result shape>" (keys and types only, P52 `AppFailureShape`). It never writes the store, never sets an alias, never runs
any other tool, and prints no key or token. Exit 0 when it ran.

## Tests
Fixtures for each app with `data` as an object and as a JSON string; Slack user @ team; a result with only an id falls
back; discovery picks only read-only no-argument tools; retry with back-off; Rename… wins; the check command writes
nothing (store and config byte-identical after). Fakes only. Files ≤ 500 lines; commit identity Konrad's noreply
address, no Co-Authored-By.
