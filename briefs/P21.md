- **D7 Re-running the wizard on a configured app.** **Same box only: it opens prefilled (address shown, key empty = keep the saved key), can add more agents, and changing the address needs an explicit confirm line ("Your agents will move to the new address.").** One global server (`hermesBaseURL`); a second box needs per-box keys (`keyAccount(forProfile:)` is per name only): out of scope. - **D8 Order.** **P18 → P21 → P20.** P20's bottom bar (`SidebarView.swift:33-37`) then builds on `UserIdentity`. If P20 merges first, P21 changes that one label.
- **D9 Not Settings.** **Right-panel items (Overview model picker `ModelSectionView`, raw cron field `RoutineEditorSheet.swift:57`, groups UI, Import template) stay as they are in P21 and become a named follow-up, "P21b: simple right panel" (add to the TODO list and say so in the report).** P17 owns model choices. Exceptions done here: both in-chat banners (`GrokHistoryView.swift`) get plain words through `SimpleCopy`; `HistoryOnlyBanner` stops linking to Settings and opens the wizard prefilled instead.
- **D10 What "Test" does on the simple page.** **Read-only**: health check of the box plus the `--check-bots` probe per agent (`HeadlessCommands.checkBot`); never adds agents or writes settings. Discovery (which adds agents) stays in the wizard and in Advanced "Test & Discover".
- **D11 Instructions in the simple editor.** **Stay simple, with a caption: "Sent with every message as the agent's standing instructions. - **D12 One noun.** **User-facing copy says "agents" everywhere in the simple page, wizard and simple editor** (today's sidebar says "bots"; renaming the rest of the app is not part of this phase). "Box" is defined once (S1): "the computer or server where your agents run".

13. **Test without side effects.** `SetupCheck` normalises the address (`BoxAddress.normalize`: trim, add `https://` if no scheme, drop trailing `/`; `HermesBackend` already strips a `/v1` suffix) and runs entirely in memory: `HermesBackend(baseURL:apiKey:).testConnection()` then `probeProfiles(named:keyFor:)`. `HermesProfileProbe` gains an additive `httpStatus: Int?` (set in the catch at `HermesBackend.swift:244-246`; `HermesProfileStatus` is not changed, so no exhaustive switch breaks) so the mapper never parses "HTTP 401: …" text. Plain lines: bad address ("That does not look like an address.
