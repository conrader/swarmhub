## How it works (proven live on stock Hermes 0.21.7, 2026-10-14)
SwarmHub sends the manager bot a short instruction text, `Resources/BotManager/manager-hermes.md` (~400 words, placeholders
`{{MANAGER}}` = the manager's profile name, `{{MANAGER_ENV}}` = `~/.hermes/.env` for the default profile else
`~/.hermes/profiles/<profile>/.env`). With it, plain Jarvis (no skill) asked first, then created `p22-vanilla-test` with stock
`hermes profile create --clone-from`, wrote its SOUL with the shell, set its key, answered PONG through the public URL with no
restart, changed it to PING (previous SOUL kept), and retired it (parked + moved to `profiles/.retired/`). After each action it
ended its reply with a fenced ```` ```swarmhub ```` JSON block, e.g. `{"op":"bot_created","name":…,"description":…,"avatar":
{"shape":"heart","colour":"cyan"}}` and `[{"op":"instructions_changed",…},{"op":"bot_retired",…}]`.
**Keys never travel:** a new bot's key = lowercase hex of HMAC-SHA256(key = the manager bot's API key, message =
`swarmhub-bot-key:v1:<name>`). The box computes it with `openssl` inside the shell (never printed); SwarmHub computes the same
value locally with CryptoKit from the manager key it already holds in the Keychain. Verified: box key == derived key.

## Must do
1. **Manager role.** A Hermes bot setting "Can manage other bots" (Advanced section of the bot's settings; one manager per
   backend connection). One-time migration: a bot bound to profile `grok-jarvis` gets it on. Non-Hermes backends: setting hidden
   (OpenClaw gets its own instruction file later, P12).
2. **On demand only (token rule).** The manager text is attached ONLY to bot-management turns, never to ordinary ones:
   (a) a "Manage bots" menu in the manager's chat (composer + menu and the chat's toolbar): New bot…, Change instructions…, Change
   avatar…, Show instructions…, List bots, Retire bot… — each fills the composer with a plain request; (b) an intent match on the
   user's text to the manager (EN + PL: create/new/make/add + bot/agent/assistant, retire/remove/delete + bot, instructions/soul/
   prompt of a bot, avatar, list bots; `stwórz/utwórz/nowy/dodaj bota|agenta`, `instrukcje`, `awatar`, `usuń bota`, `lista botów`).
   An exchange stays "open" (text attached to follow-ups such as "yes") until a swarmhub block arrives, 3 user turns pass, or 10
   minutes pass. Attach it the way the bot's Instructions already travel (session system prompt for that turn), placeholders
   filled. Find in `HermesBackend` how history is sent and make sure the text does not ride along on later ordinary turns.
3. **swarmhub blocks.** Parse the last ```` ```swarmhub ```` fence of a manager reply (object or array); hide the fence from the
   chat view (the stored message may keep it); ignore anything malformed or unknown (log the op name only). Apply:
   - `bot_created`: derive the key, probe `/p/<name>/v1/models` (a few retries over ~10 s) → Keychain `hermes.<name>` → new bot
     bound to that profile on the manager's connection (display name from the slug, description as subtitle, avatar mark from the
     block else derived) → small notice "Jarvis created <Name>". Probe failure: keep nothing, notice "couldn't reach <name> yet".
   - `avatar`: set `avatarMark` (validated by `AvatarLook`) on the bot bound to that profile (the manager itself included).
   - `description` / `instructions_changed`: update the bot's subtitle / mark its box instructions stale.
   - `instructions`: store `{text, fetched_at}` as the bot's last-known box instructions.
   - `bot_retired`: move the bot to Hidden chats with a "retired on box" label; never delete its history.
   - `bots`: for each listed profile not in SwarmHub offer "Add" (derive + probe; 401 → the existing paste-key flow).
4. **Instructions in the bot editor.** Show "Instructions on the box" (last-known text + time, or "not loaded") with buttons
   "Load from box" and "Ask <Manager> to change…" — both open a management turn in the manager's chat (on demand). The local field
   is relabelled "Extra instructions for this app" (content kept).
