# P56 — Bots know SwarmHub manages their heartbeat

Konrad, 2026-10-16 19:23: "I just asked jarvis about heartbeat but he was unaware - check" … "yes" (build). Not released
until Konrad names a release.

## Evidence
Jarvis answered "do you have a heartbeat setting which is not a routine ?" correctly (no: his hourly 08–23 CET heartbeat
is a routine; Hermes 0.22 has no other kind). The gap: nothing tells a bot that SwarmHub manages that routine (P46:
Settings → Advanced → Heartbeat, `/heartbeat every …`, the chat Heartbeat bar, routine `swarmhub-heartbeat` or an adopted
one such as `jarvis-hourly-heartbeat-cet`).

## Fix
1. **Turn context.** Every turn SwarmHub sends to a Hermes bot carries one short line when the bot has a heartbeat:
   "Your heartbeat: routine <name>, <plan label>, next <time>. Konrad changes it in SwarmHub (Settings → Heartbeat, or
   /heartbeat every …)." When it has none: "No heartbeat is set; Konrad can turn one on in SwarmHub." Keep it to one line;
   put it where the other SwarmHub context lines go (same place as the connected-apps context), not in the user's text.
2. **Skill.** `Resources/Skills/swarmhub-manager/SKILL.md` gets a "Heartbeat" section and a minor version bump: the
   heartbeat is a routine SwarmHub manages; to change its frequency or hours when Konrad asks, edit **that** routine's
   schedule with the cron tool (never create a second heartbeat routine), keep its `deliver: bot-chat:<profile>`, then say
   what changed; SwarmHub reads it back. If the skill install path (`AppStore+SkillsAllBots.swift`) tracks versions, the
   new version is offered as an update like other skill updates.
3. **Changed on the box.** When the routine's schedule on the box no longer matches the plan SwarmHub set, Settings →
   Heartbeat shows "changed on the box: <box schedule>" with **Use the box's schedule** (adopt it as the bot's plan) or
   **Put mine back**. SwarmHub never silently overwrites it.
4. Tests: the context line with and without a heartbeat (and an adopted routine's name); the skill text contains the
   section and the new version; a box-changed schedule shows the notice and both buttons work (fake jobs client). Render
   (`--only p56`): Settings → Heartbeat with a "changed on the box" row.
