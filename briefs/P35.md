# P35 — Connecting a box adds every bot on it

Konrad, 2026-10-14: "When I'm connecting to hermes box by wizard we should automatically add everything there is";
"I think swarmhub should list all bots made in hermes before". **Accepted by those messages; defaults below.**

## Why bots are missing today (Konrad's box, 2026-10-14)
The box has 23 profiles; SwarmHub has the 16 `grok-*` bots (Grok import) + 5 sample bots. Missing: `default` (Ermes,
Telegram/WhatsApp/cron, used today), `lowcost` (Ermes copy, used today, no API key), `cfo`, `krytyk`, `sekretarz`,
`wingman` (Ermes personas, last used August), `knowledge-guide` (never used). SwarmHub reaches a bot only with that
bot's key; bots the manager created get P22 derived keys, these were made before with their own keys, and Hermes takes
one `API_SERVER_KEY` per profile (no second key).

## Decisions
- **D1 Discover everything**: after the wizard's Test succeeds (and on every launch / Settings → "Add all bots from
  this box"), the connected Hermes bot reports the box's profiles (the manager's `bots` op, P26, from
  `ls ~/.hermes/profiles` + `default`). The first connected Hermes bot becomes the connection's manager when there is
  none (wizard line: "<Bot> will set up the other bots on this box.").
- **D2 Add what is reachable at once**: a profile answering `GET /p/<profile>/v1/models` with its P22 derived key is
  added silently.
- **D3 Adopt the rest automatically, reversibly**: for each other profile the manager backs up its `.env` to
  `.env.swarmhub-bak-<UTC stamp>` (0600) and sets `API_SERVER_KEY` to the P22 derived key (adds it when the profile
  has none, e.g. `lowcost`), then SwarmHub probes and adds it. One recipe in the manager text, one confirmation for
  the whole batch, a `swarmhub` op `bots_adopted` with per-bot ok/failed. Undo per bot: restore its backup.
- **D4 Never re-key the box's main bot**: `default` (and any profile whose key the user typed in the wizard) is never
  re-keyed — getermes' own web chat uses it. If `default` is not connected yet, SwarmHub asks for its key once (the
  existing paste field), with the reason in one line.
- **D5 Nothing silently missing**: any profile left out (adoption failed, `default` without a key) is listed in the
  sidebar under "On this box · not connected" with Connect (paste key, or retry adoption).
- **D6 Sample bots go away** once a real box is connected (they stay only in the "Look around with sample agents"
  path); their chats are not migrated.
- **D7 Konrad's box**: after this ships, "Add all bots from this box" adopts cfo, krytyk, sekretarz, wingman,
  knowledge-guide and lowcost, and asks for Ermes' key.
