## Rules for every part
- **Main wins where both exist.** Before porting a file, check whether main already has the feature under another name
  (`git grep` the symbols). Port what is missing; extend main's version where the old one does more; never replace a
  main design wholesale. List each such call in the report.
- **Skip (main already has it, newer):** the old setup wizard (`SetupFlow`/`SetupView`/`FirstRun`/`SetupPreview`,
  `--setup-preview`, "Ermes placeholder"), `OpenClawConnection.swift` + `OpenClawSetupView.swift` (main has the P25/P26
  Gateway stack), avatar engine, PDF/OCR attachment reader, Sparkle/appcast scripts, the Grok export/import scripts.
- **Server side stays in `conrader/swarmhub-backend`** (it already has `services/composio_provisioner`, the connector and
  the configure/deploy scripts). This phase changes the app repo only. Nothing is deployed.
- Honest states: a feature whose service is not set up (backend sign-in and Composio are unconfigured in production; the
  deAPI key may be missing) shows a plain "not set up" line with what is needed. No dead controls (P32).
- Tests never open a browser or app (ExternalLink), never reach the network beyond loopback, the real Keychain or the
  microphone; clocks/sleeps are injected (testspeed). Files ≤ 500 lines. Commit identity: Konrad's noreply address, no
  Co-Authored-By.
- Runs are short (PLAN "How the work runs"): `swift test --filter` while working, one full run at the end; renders only
  for screens the part adds.
