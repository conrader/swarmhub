# Changes since SwarmHub 0.8.17

- Press ⌘K to open Pages shared in your chats by title. Browse or search published Pages by workspace from the switcher or a bot’s Media tab. Chat results open the shared revision. The workspace library opens the latest version.
- Switching conversations in a large sidebar is faster. In a MacBook test with 50 chats, the 95th percentile for showing the newest message fell from 235–243 ms to 216–219 ms.
