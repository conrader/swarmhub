# SwarmHub 0.8.33

- In a bot’s **Details → Approvals → Edit**, choose another Claude bot on the same workspace to review Codex shell commands. Each review uses the selected bot’s model and standing instructions in the background, leaving its chat available.
- The approval shows who reviewed the command. If the selected bot becomes unavailable, the approval tells you. Completed named reviews are also visible in the workspace’s approval history. Requires workspace 0.2.20.
