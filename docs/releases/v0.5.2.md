**SwarmHub 0.5.2**

- **Coding model**: see and change the model a bot's sub-agents use (and coding jobs when no coding agent can run): Overview → "Coding model", or Manage bots → "Change coding model…". "Same as this bot" clears the pin.
- **Box capacity**: Settings → Models shows what your box can take ("2 CPUs, 3.8 GB — 1 coding job at a time"), advice when jobs queue, and "Set limit…".
- **Connected apps** (Settings → Connected apps): Composio apps and your ChatGPT connection. Every app action asks you first. Needs SwarmHub sign-in, which is not switched on yet; the pane says so.
- **Voice**: live voice with your ChatGPT account through Codex, dictation into a message draft (deAPI key), saved voice conversations. macOS asks for the microphone the first time.
- **Workflows in groups**: "Plan a workflow" in the group header; you approve the plan before it runs. Missed routines catch up, delegated tasks get one card each, and a local run ledger keeps track.
- **Usage and documents**: token usage per bot on the Activity tab; saved documents on the Media tab.
- Safer setup (a failed save rolls back), managing disconnected bots from the sidebar, steadier streaming.
