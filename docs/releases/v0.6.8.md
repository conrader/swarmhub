SwarmHub 0.6.8 (build 33). Notarized. A dropped or flaky network no longer opens "The network connection was lost." or other connection popups: a message that never left the Mac is sent again by itself with "Reconnecting…" on its row, and anything left after the retries is one small line at the bottom of the window. Skill installs are sturdier: an install the network interrupted is sent again in a fresh setup session, and a release build has the box fetch the skill files it ships unchanged straight from this release's commit on GitHub, checked against a digest before anything is written, so even large skills install completely on every bot. A message typed while a bot answers now steers the running answer instead of interrupting it; if the answer is already finishing, the message goes as the next one by itself. swarmhub-messages 1.4.15 brings webhook receiver fixes (a `message` field, body-key fallback, per-account ports) to existing bots. Off-app alerts stay switched off for now, as in 0.6.7. Ships without the embedded baseline; signed baseline (P1b) follows in a later release.
