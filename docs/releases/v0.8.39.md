# SwarmHub 0.8.39

- In Settings for a standard Claude bot, turn on **Ask before every tool call** under its approval controls. New sessions and Claude helpers send each tool call to Needs Attention, including repeated reads of the same file. An approval applies once. Retained command rules and Auto mode cannot approve these requests.
- **Create with Claude** in a sensitive role proposal sets up tool review before adding the bot. Update the workspace server to 0.2.22 and install Claude there to use this feature. A proposal stays in the Inbox if the server cannot enable review.
- A protected bot carries its tool review setting when moved between supported workspaces. An incompatible destination is reported before interrupting work.
