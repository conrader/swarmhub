# SwarmHub 0.8.61

- Ask Jarvis to create an OpenCode bot with a USD session limit. The proposal, sidebar and bot details show the limit. SwarmHub confirms the limit on the workspace before creating or moving the bot.
- On workspace 0.2.34, each model request in the same private OpenCode session reserves its maximum token cost at the configured model prices. Simultaneous requests share the allowance. A complete usage receipt releases the unused amount. Chat explains when the model or the remaining budget cannot support another request.
- The limit applies to ordinary chat and to native OpenCode children in that session. A new session gets a new allowance. Separate helper processes, external tools and non-token provider fees fall outside it.
