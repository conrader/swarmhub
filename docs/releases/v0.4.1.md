SwarmHub 0.4.1 (build 6) for macOS 14+ on Apple silicon.

- PDF, Word and RTF attachments, read on your Mac (on-device OCR for scans); long text files arrive whole
- Your main agent can create agents and change their instructions and avatars (stock Hermes; nothing installed on the server)
- Sidebar shows each chat's latest message; Navigate and Chat menus with keyboard shortcuts
- Each server's Hermes version shown in Settings; double-clicking the top bar zooms the window
- Automatic updates (Sparkle, signed): this is the first build that can update itself

Signed with an Apple Development certificate, not notarized: on a Mac other than the developer's, open it with right-click → Open the first time.
