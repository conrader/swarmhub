**SwarmHub 0.5.7**

- **Chats open where you left them**: each chat, group and thread remembers its scroll position, also after a relaunch. A chat you never scrolled opens at the newest message. When you are scrolled up, **Jump to latest · N new** takes you down. New messages only scroll the view when you are already at the bottom.
- **Technical rows fold into one line**: app calls, SwarmHub instruction updates, the skill text routines load, and messages between bots now show as one short line ("Jarvis used GitHub · Get the authenticated user · ok", "Heartbeat · uses skill …", "Infra → Jarvis: …"). Click to see the full text. Previews, notifications and unread counts use the short line.
- **Safer approvals**: approval rules now auto-approve only plain read commands (such as `ls`, `cat`, `grep`, `git status`); actions that send, write, edit, create or delete always ask you.
- **Safer recovery**: a message that was being sent when the app quit is shown as "delivery uncertain" instead of being sent again, and retry only resends when the box clearly lacks the message.
