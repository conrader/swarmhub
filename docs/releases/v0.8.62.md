# SwarmHub 0.8.62

- Moving an OpenCode bot with routines can prepare its session on the destination before interrupting an active chat. The workspace opens the private session and binds the routine without spending tokens on a placeholder message.
- The first real message uses the bot’s instructions, model and session spending limit. For this workflow install workspace 0.2.35 on the destination.
- Stop and active moves use OpenCode’s session interrupt on a workspace with the new private API launcher. The app checks that work stopped before continuing on the other machine.
