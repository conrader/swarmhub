**SwarmHub 0.5.5**

- **Heartbeat the Hermes way**: a heartbeat is now one Hermes routine per bot (`swarmhub-heartbeat`), set up under Settings → Advanced → Heartbeat with a shared template, **Apply to all** or to chosen bots, active hours, a turns-per-day estimate and a cap from your box's capacity. Nothing runs until you apply it. Each bot's main chat is titled "Bot Chat" on the box so the routine answers there; if another chat already has that title, SwarmHub asks before moving it (**Use this chat**). A wake shows as "Woken by: heartbeat"; a run with nothing to say (`[SILENT]`) stays hidden. Replaces 0.5.4's in-app heartbeat timer.
- **Team coordination**: in a bot chat, `@Peer your request` hands work to another bot through SwarmHub itself. In a group, **Work together** lets members help and review each other inside one task. The team card shows tasks, delivery state and results, with **Pause new work**, **Cancel queued work** and limits. Shared project facts (book button) go into ordinary requests. Work is only sent while SwarmHub is open and connected; nothing is installed on Hermes.
- **See what bots do for each other**: messages between bots show in the recipient's chat as they arrive, with the work it does for the other bot, and a busy avatar while it works.
- **/ commands**: type `/` in any chat for the command list, including `/goal` (keeps the bot working toward a goal until done), `/loop` and `/heartbeat`.
- **Routines**: **Run now** shows that it is running, the list refreshes quickly after a bot creates a routine, and a finished run posts a card with the full result.
- **Fixes**: the back button inside threads works; the final answer appears after the tool steps, not above them; steer messages no longer show Hermes's raw out-of-band wrapper after a reload; routine results that are exactly `[SILENT]` are hidden.
