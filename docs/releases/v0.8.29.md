# SwarmHub 0.8.29

- **Details → Routines** now shows enabled skills from the bot’s server library. Expand a long list, retry an unavailable server, or choose **Manage** to open Skills.
- **Details → Approvals** shows the selected bot’s saved mode for new sessions, command reviewer and scoped command rules. Choose **Edit** to change the controls.
- Project and skill names fit side by side when space allows. Long names stay within the panel and reveal the full text on hover.
