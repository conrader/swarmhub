# SwarmHub 0.8.43

- Expand a bot in the sidebar to see the agents Codex spawns inside its own session. Each row shows the agent’s name and its current task or saved answer.
- Click a Codex agent to read its activity in the right panel while keeping your current chat open. Working agents also appear in Live terminals. A saved session stays readable after its parent closes.
