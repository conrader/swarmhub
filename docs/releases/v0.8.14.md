# SwarmHub 0.8.14

- Turning on **Auto mode** for a bot now replaces unused warm sessions immediately and carries active conversations into a fresh Auto mode session on your next reply.
- In Auto mode, Codex, Claude Code, Gemini (Antigravity) and OpenCode run without blocking on terminal permission prompts, Computer Use app prompts, hook review prompts or staged handoff files.
- Gemini (Antigravity) bots automatically trust the private workspace folder SwarmHub created for them and start isolated conversations without picking up shell `--continue` wrappers across bots.
- Bots keep access to Pages they published after switching models or starting a fresh session, and clearing a terminal prompt updates the chat header immediately instead of leaving “Check terminal” showing. Requires workspace server 0.2.11.
