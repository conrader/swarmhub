SwarmHub 0.6.7 (build 32). Notarized. Installing a skill now runs in its own short-lived session on the box, so a long conversation with your manager bot can no longer make the install fail, and an install that did not reach the box retries by itself. When a chat grows too long for the model, SwarmHub recovers on its own: it lets the box compact the conversation, or continues in a new session with your message resent, and says so in the chat instead of showing Hermes' /new and /compress advice. If your bots file is missing or unreadable, SwarmHub offers to restore the newest backup that loads. Off-app alerts stay switched off for now, as in 0.6.6. Ships without the embedded baseline; signed baseline (P1b) follows in a later release.
