# SwarmHub 0.8.22

- Open **Terminal** in Details to watch the selected bot or helper while you keep typing in chat. Drag the divider to scale the entire terminal, including the text, at the running session’s row and column count. Live terminal mirroring requires workspace 0.2.16.
- Expand a bot in the sidebar to open a helper’s terminal. In a group, choose **Terminals** to see its running sessions and detached coding workers. Detached workers show their latest log output. **Live terminals** opens a separate window.
- When moving a bot home, the move window identifies a disconnected source. Sign in there if the source needs a password, or start its workspace over SSH if the service is down.
