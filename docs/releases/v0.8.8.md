# SwarmHub 0.8.8

- Bots imported from Grok Bot can carry on where they left off. Before a bot's next reply, its agent reads the imported conversation: a summary of the older part, the recent part word for word, and the full transcript to search. Long conversations are summarised once. This also applies to bots you imported earlier, with no new import. You can switch it off per bot under the chat's Grok history header; if it cannot be handed over, your message still goes through and the chat says so.
- The bot list can be divided into named sections that fold and unfold, and up to nine bots or groups can be pinned to the top as large avatars with their names. Use a chat's menu (**Pin**, **Move to Section**) or **+ → New Section…**.
- Import from Grok Bot: when Grok refuses or cannot give the full history, the import says what Grok said and brings in the recent messages kept on this Mac instead of stopping, and opens on Recent messages the next time. A problem with one chat no longer affects the others, and chats that only got recent messages stay under **Retry remaining**.
- The import sheet is easier to read: the history choice is two large cards, each step has one clear action, and progress shows one line per chat.
- Secret-like text is recognised in more shapes (quoted and bold labels, escaped JSON) and ordinary code is left alone more often. Saved history is filtered again the next time a chat is imported.
