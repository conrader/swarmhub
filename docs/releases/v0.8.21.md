# SwarmHub 0.8.21

- Open Needs Attention above the bot list to review pending commands, interrupted chats and failed checks. The badge counts pending decisions. The sidebar also shows configured SSH hosts and workspace bots.
- Jump to a bot or Page with the sidebar search field. In Details, open Approvals to review a request or change the bot’s reviewer and Auto settings.
- Choose a screenshot from the composer. Press /goal to turn the current draft into a goal, or ⌘↵ to send it.
- In a priced OpenCode session, enter `/goal --budget 2.00 review the changes` to check session spending before every automatic step. The limit uses USD estimates from OpenCode, including earlier activity in the same session. A step already running can exceed it. Missing usage pauses the goal.
