# SwarmHub 0.8.28

- **Details** now shows **Overview**, **Approvals** and **Routines** in one compact row. Choose **More** next to Terminal to open **Model**, **Team**, **Skills** or **Media**. The button shows the current section while you are there.
- Overview lists the selected bot’s project servers and folders. Choose **Edit** beside **Projects** to change its assignments. A failed project-list refresh preserves the saved assignments.
