# SwarmHub 0.8.10

- Available updates now appear just below the sidebar search controls. Choose **Review updates** to open Software Update. When both the app and servers have updates, the card shows the app version and the number of servers.
- Agents can now explore sample chats headlessly on a Mac, check how the app behaves, and save screenshots and replayable bug reports. Run the app executable with `--agent-qa OUTPUT_DIRECTORY --hunt` for the built-in checks.
