# SwarmHub 0.8.15

- **Routines & Webhooks tab:** View, create, edit, pause/resume, test-run, and inspect history for a bot’s routines directly in the right-side Details panel, including Generic, GitHub, and Slack webhooks with JSON filters, one-time secret key rotation, and pending review approval.
- **Interactive chat cards:** Clear plain-text choices and `choices` blocks now render as tappable buttons (with **Other** for custom replies), and proposed emails or outbound messages render as reviewable **Draft** cards with inline **Edit**, **Copy**, and **Send**.
- **Cleaner Markdown & UI:** Assistant replies now properly format headings (`#`–`######`), blockquotes, dividers, lists, and tables; the Details panel collapses long instructions to 3 lines with Show more/less; AI selector buttons share uniform height, an inline **Default** badge, and clean names (`Claude`, `Codex`, `Gemini`).
- **Live coding agents & terminal viewer:** Bots with running coding agents (helpers) stay animated on their avatar with a terminal badge and show an in-chat bar with one-click live terminal access, alongside a Terminal button in the chat header.
- **Configurable concurrency & delivery fixes:** Set per-server and app-wide concurrent reply limits under **Settings → General**, settle mid-turn steer bubbles cleanly when 0-tool replies finish, pre-allow SwarmHub handoff files for Claude bots, and safely recover when a terminal swallows input (`start_not_observed`). Requires workspace server 0.2.12.
