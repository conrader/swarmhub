SwarmHub 0.6.5 (build 30). Notarized. The Dock icon is now Light by default, whatever the theme; pick Dark under Settings → Appearance → App icon. Webhooks work out of the box: skill setup installs a supervised loopback receiver on each box, the app has a Webhooks pane with delete, and upgrades restart a receiver whose code changed. Off-app alerts: a per-server alerts pane, and the box reports finished routines, code jobs, reports and webhook wakes (ntfy or email) while the app is closed; a /loop or /goal keeps running on the box after you quit and is taken back when the app returns. Bots offer a routine when you ask for the same thing repeatedly (a chat message with quick replies). Grok import now brings routines and connector requests along, staged and inert, through the hardened secret filter. swarmhub-coding 1.3.15: after a deadline, code-job keeps stopping a job's process tree until all of it is gone, signalling only processes it can verify as its own. swarmhub-messages 1.4.12. Ships without the embedded baseline; signed baseline (P1b) follows in a later release.
