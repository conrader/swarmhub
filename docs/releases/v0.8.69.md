# SwarmHub 0.8.69

- In a group’s **Members** panel, choose **Skills & handoffs…** for a bot. Write skill instructions or copy a saved workspace skill, and choose when the bot should hand a task to another member.
- Export a Team Pack to share those workflows. On import, expand each member to review the skills and handoff rules. Handoffs point to the newly imported teammates, even if another bot has the same name.
