# SwarmHub 0.8.127

- When a model change has to wait for a bot’s helper or command approval, your next chat message stays in the queue. You can close and reopen SwarmHub. Once the session can switch, SwarmHub sends the waiting messages in order.
- On workspaces that support safe model switching, a helper that has finished and recorded its answer can stay visible in the sidebar while the parent starts using the selected model.
- In the sample Inbox, Patch’s command and Jarvis’s bot proposal keep their places when you decide. A checkmark replaces each card’s actions. Your workspace Inbox also keeps its last 20 confirmed decisions across launches.
