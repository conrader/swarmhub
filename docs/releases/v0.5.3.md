**SwarmHub 0.5.3**

- **Workflow handoffs and reviews**: inside a group workflow, bots can hand work to each other, ask for help, or ask another bot to review. One revision is allowed, then a second review; if problems remain, the workflow waits for you to **Accept review with noted limitations** or cancel. New handoff tasks wait for your approval.
- **Queued messages survive a restart**: unsent messages resume in order when SwarmHub reopens, never sent twice. If an earlier reply isn't confirmed, you get the message back with **Send as next message**.
- **Dark Dock icon** in dark mode.
