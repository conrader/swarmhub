SwarmHub 0.8.0 (build 34). Notarized.

**Read this before you install.** SwarmHub now runs its bots on Herdr Core, and only there. Bots from earlier versions (the ones that ran on Hermes or OpenClaw) do not carry over: on first launch, 0.8 saves a copy of your data next to it (`store.json.before-herdr-only-…` in `~/Library/Application Support/AgentApp`) and then removes those bots and their chats from the app. If you still rely on them, choose **Skip This Version** and stay on 0.6.8.

To use 0.8 you need Herdr Core and the SwarmHub service running on the computer where your bots work. Today that is a Linux server (x86_64); the first install is by hand and the guide says how. After that the app keeps the service up to date.

What is new:

- **Bots are real agent programs.** Each bot is Claude Code or Codex running on your server. You choose the AI and the model per bot, from what the server offers.
- **A setup window** that ends in your main bot's chat: choose where bots run (this Mac or a server you reach with your SSH login), connect, name your main bot.
- **Your main bot says hello.** It introduces itself and asks a few short questions, one at a time and skippable. What it learns goes into "About you" only when you agree, and every bot reads it.
- **Replies appear as they are written**, with each step the bot takes. A message you send while it answers goes into the running answer.
- **A fast first answer.** Opening a chat starts that bot's agent in the background, and the chat says what it is waiting for.
- **One main bot** (marked with a star) creates other bots, at once or after asking you. Other bots ask the main bot.
- **Helpers.** A bot can start short-lived helpers for parts of a task. The server decides which model a helper gets by how hard the task is. Helpers show under their bot and disappear when done.
- **Bots write to each other** by name. Both chats show the message and the answer.
- **Skills** from the server's shared library, switched on or off in the app.
- **Project servers.** Add the servers where your projects live and choose which bots may work there.
- **Software Update** shows the app, each server's SwarmHub service and Herdr Core in one place, with one button when something is behind. Checks are quiet; nothing opens over your work.
- **A warmer look** with a new app icon, plain words throughout, and one Settings window.

Removed: the Hermes and OpenClaw connections, live voice, routines, reports, and the iPhone app.
