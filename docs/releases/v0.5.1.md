**SwarmHub 0.5.1**

- **Reviewer rules**: per bot and for all bots — "when <what> → Ask me / Approve / Reviewer: <bot> / Deny" (by kind of action, command pattern like `git push*`, or target bot). One line "anything → Reviewer: Jarvis" makes Jarvis review every bot. Safety rails still bring risky commands to you. **Review after**: e.g. when a bot finishes a coding job, a reviewer bot looks at it and leaves "Looks good" or "Changes requested" with notes you can forward in one click. Settings → Approvals.
- **Reports to SwarmHub**: bots can file bug reports and feature requests (`swarmhub-feedback` skill); they wait in the new **Reports** inbox, where you edit and **Send to SwarmHub** or Dismiss. Help → Report a Problem… for your own. Nothing leaves without your click; sent reports show their status.
- **Accounts**: install Claude Code and Codex CLI on your box and log in from SwarmHub (Settings → Advanced → Servers and keys → Accounts…, or the Coding agent area); see your ChatGPT accounts for conversation.
- **Smaller manager instructions**: a one-line pointer when the SwarmHub skill is installed; the box and account recipes load only when needed.

After updating, Jarvis shows an **Update** banner for the SwarmHub skills.
