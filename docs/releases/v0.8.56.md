# SwarmHub 0.8.56

- Expand a Gemini bot in the sidebar to see its delegated sessions as soon as Gemini starts them. Helpers with the same name have separate tasks and results.
- Select a session to read its task, tool activity and reply. The right panel can show its recorded output. Completed sessions also show the child model when Gemini reports it and stay available after the bot closes.

These changes require workspace 0.2.33, included in this release.
