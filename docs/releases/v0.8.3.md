SwarmHub 0.8.3 (build 37) simplifies connecting to a server from your Mac.

- Enter a hostname, an SSH alias, or a login such as `deploy@studio`. You can also paste `ssh deploy@studio`. Open **Connection details** if you need a custom key file.
- SwarmHub tries your SSH settings first. If key login fails and the server accepts passwords, it asks for your username and password. It keeps a successful password in memory until you quit. Use **Settings → Servers → Check connection** to sign in again.
- This update is for the Mac app. It works with workspace 0.2.2.
