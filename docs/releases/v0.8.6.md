# SwarmHub 0.8.6 (build 40)

- Check for Updates stays available. Updates replace SwarmHub in place and leave one installed copy.
- First run asks where your bots live before offering to import from Grok Bot. The import shows the destination and each bot, keeps the full history, and flags missing descriptions.
- Restore previews exactly what will come back, protects a healthier store, and offers Undo.
- Each bot gets its own workspace with Claude folder trust already set. SwarmHub no longer shows “waiting” when a bot is ready.
- Service downloads show progress and let you stop or retry.
- The Astra bug hunt fixed attachments going to the wrong recipient, long messages getting cut off, tasks sending twice, group and direct chat turns clashing, and incorrect unread counts.
