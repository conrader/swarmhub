**SwarmHub 0.5.0**

- **Overview split into tabs**: Overview · Model · Skills · Activity · Routines · Media · Computer, with one-line pointers when another tab needs you.
- **Bot-to-bot messages**: a new SwarmHub skill gives every bot `bot-msg`; the recipient's avatar shows on the step, a click opens the thread between the two bots, and the receiving bot's feed says "Jarvis wrote to Infra". Threads are in the Activity tab and ⌘K.
- **Every bot on the box**: connecting a box finds all its bots; bots made before SwarmHub can be connected in one confirmed batch (each key file backed up first, undo per bot). The box's main bot is never re-keyed. Sample bots are removed once a real box is connected.
- **Coding agents (first part)**: a per-bot "Coding agent" setting (Claude Code → Codex → Hermes sub-agent) and a SwarmHub `code-job` queue on the box. Logins come in a later release.
- **Model label**: a chat you haven't pinned shows the bot's current model, with "last reply: …" when the last reply ran on another one.
- **Faster model switch**: the recipe skips values a bot already has and runs two bots at a time (SwarmHub skill update).
- **Steps row**: unfolds while the bot is still working and stays open when it finishes; Thinking / Typing / Working states.
- **Kept promises**: sample agents without dead buttons, delegated tasks in Activity, honest memory line, ⌘K arrow keys, install imported template skills, "Send as next message" for a correction that didn't land, Settings links that open the right pane, updated docs.

After updating, Jarvis shows an **Update** banner for the SwarmHub skills.
