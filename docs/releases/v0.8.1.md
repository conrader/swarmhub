SwarmHub 0.8.1 (build 35) and workspace 0.2.1.

**Upgrading from 0.6.x or earlier?** SwarmHub now runs bots on Herdr Core. On first launch it backs up your store alongside `store.json` and removes Hermes and OpenClaw bots and their chats from the app. If you still rely on them, choose **Skip This Version**. The [0.8 migration notes](https://github.com/conrader/swarmhub/blob/herdr-workspace/docs/releases/v0.8.0.md) explain the change.

- Choose Codex, Claude Code or an API provider for each bot. Use the recommended model or choose your own.
- Change models in an existing conversation. Claude Code and Codex use their session pickers, and OpenCode applies the change directly. **Advanced → Start fresh** starts a conversation with empty context.
- Respond to supported approval prompts and open published files and Pages from the Mac chat.
- Bots can hand off work and run check-ins while the Mac is closed. **Details → Team activity** shows open exchanges, plans and promises.
- Ask a bot to watch a public GitHub pull request. The bridge checks for failed CI without model turns and wakes the bot on the first observed failed check.

Use **Settings → Software Update** to update the workspace on each server.
