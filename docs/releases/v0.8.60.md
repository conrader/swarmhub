# SwarmHub 0.8.60

- In the composer, choose **/goal → Budget…** to set a USD limit for this goal or the entire session. Review the draft and send it when ready. The goal card and **Details → Overview** show the current estimate and limit.
- Start a goal with `/goal --goal-budget 2.00 review the changes` to give it its own USD limit in a priced OpenCode session. Earlier chat activity does not consume the new goal’s allowance.
- SwarmHub checks the estimate before starting another step. A running step can exceed the limit. Pending readings and recorded spending survive restarting the app. The existing `--budget` option continues to enforce a ceiling on the whole session.
