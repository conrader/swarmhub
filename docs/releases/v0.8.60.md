# SwarmHub 0.8.60

- Start a goal with `/goal --goal-budget 2.00 review the changes` to give it its own USD limit in a priced OpenCode session. The goal card shows the cost measured for its steps. Earlier chat activity does not consume the new goal’s allowance.
- SwarmHub checks the estimate before starting another step. A running step can exceed the limit. Pending readings and recorded spending survive restarting the app. The existing `--budget` option continues to enforce a ceiling on the whole session.
