SwarmHub 0.8.2 (build 36) and workspace 0.2.2.

- SwarmHub runs bots on Herdr Core. The retired Hermes and OpenClaw integrations have been removed. When opening an older store, SwarmHub keeps its Herdr bots and groups and drops references to retired bots.
- Use the Vault to enter secrets securely from the Mac app or browser. Managed agents can request a named credential, and you can approve a single command or grant limited reuse.
- Vault approvals now stay tied to the session that requested them. Reusable approvals enforce their time and use limits, and Vault masks credential values in captured command output.

Use **Settings → Software Update** to update the workspace on each server.
