# SwarmHub 0.8.70

- A helper’s task or latest answer gets the full second line in the sidebar. Its terminal and disclosure stay beside the title.
- SwarmHub remembers which workspace helper branches you closed when you return or reopen the app. A new launch opens independently.
- Agent QA can follow a provider thread back to its workspace helper, fold that branch and inspect its live terminal.
- If a helper’s history cannot be loaded, its details show which information is unavailable. Choose **Retry history** to fetch it again in the same session.
