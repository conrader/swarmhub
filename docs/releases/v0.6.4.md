SwarmHub 0.6.4 (build 29). Notarized. New bots now start with read-only default connectors only; you turn on more connectors per bot (opt-in), and a tool or connection that fails to load is now shown instead of silently missing. Hermes replies are recovered when the stream drops mid-turn, and Hermes internal notes are folded into a single "Internal activity" line. Installing skills on all bots is much faster (batched turns, verified copies, one peer call). Bots now shut down cleanly when the gateway stops (swarmhub-messages 1.4.10). Process-safety fixes: process-tree cleanup only ever stops processes it can verify as its own, never broadcast or foreign process groups. Ships without the embedded baseline; signed baseline (P1b) follows in a later release.
