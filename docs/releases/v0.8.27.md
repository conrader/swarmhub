# SwarmHub 0.8.27

- Open **Details → Overview** to see the selected bot’s context meter when its runtime reports a context window, its conversation token total, and estimated session cost when available. The panel distinguishes an idle bot, missing usage, and a disconnected workspace.
- The smaller profile header leaves more room for the bot’s instructions, usage and projects. **Summarize & start fresh** is now available directly from Overview for conversations with a saved reply.
