# SwarmHub 0.8.57

- Open a Claude, Codex, Gemini or OpenCode helper under its bot and choose **Promote to bot** to start a permanent chat with its saved session history. The new bot uses the helper’s program and, when available, its reported model.
- You can promote a helper while it works and message the new bot immediately. SwarmHub updates its copy of the original session record after the helper finishes. Returning to the same helper opens its existing chat.
